# 🎓 Student CRUD System (PHP + MySQL)

## 📌 Description
This is a simple Student Management System built using PHP and MySQL.  
It performs CRUD operations (Create, Read, Update, Delete).

---

## ⚙️ Features
- Insert student details
- Update student contact
- Delete student record
- Display all students

---

## 🛠️ Technologies Used
- PHP
- MySQL
- XAMPP

---

## 🚀 How to Run
1. Start XAMPP (Apache + MySQL)
2. Import database
3. Place files in htdocs
4. Run: http://localhost/assignment4
